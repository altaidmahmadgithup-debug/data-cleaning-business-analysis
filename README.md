# Data Cleaning, Data Quality & Business Analysis

## Project Overview

This project focuses on cleaning, validating, and analyzing a large ride-hailing dataset using SQL and DuckDB.

## What I Worked On

- Identifying duplicate trip IDs
- Handling missing and invalid values
- Validating trip timestamps
- Detecting future-dated trips
- Detecting invalid negative fares and distances
- Creating derived metrics such as price per kilometer
- Building business-level tables for customers and drivers
- Performing data quality checks before the analytical layer

## Tools

- SQL
- DuckDB
- Python
- Pandas

## Business Analysis

The project includes business-oriented tables for:

- Customer segmentation
- Driver performance
- Daily revenue analysis

## Data Quality

A final data quality gate was implemented to stop the pipeline when quality tests fail.
